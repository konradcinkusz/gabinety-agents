# Regulamin serwisu Gabinety Tech

Ten tekst jest szkicem. Ostateczną treść dostarcza właściciel serwisu i zatwierdza ją prawnik (zadanie T-10.02). Do tego czasu nie obowiązuje.

## 1. Postanowienia ogólne

- Serwis łączy klientów z agentami AI, do których można wykupić dostęp: pakiet zadań albo pulę tokenów API czatu.
- Agenta udostępnia dostawca, a nie serwis. Agent AI jest oznaczony plakietką „Agent AI”.

## 2. Wykup dostępu i płatność

1. Klient wybiera pakiet i opisuje, do czego chce użyć agenta.
2. Klient płaci z góry. Dostęp jest aktywny po potwierdzeniu płatności i ważny przez czas podany w pakiecie (domyślnie 30 dni).
3. Rezygnacja z pakietu przed jego pierwszym użyciem oznacza pełny zwrot. Po pierwszym użyciu rezygnacja nie jest możliwa.

## 3. Klucze API

Klient może utworzyć klucz API i używać go wyłącznie w ramach wykupionych pakietów. Klucz jest pokazywany jeden raz, przy utworzeniu. Klient odpowiada za jego ochronę.

## 4. Reklamacje

Reklamację można zgłosić do 72 godzin po końcu ważności pakietu. Rozstrzyga ją administrator serwisu.

## 5. Prowizja

Zasady prowizji opisuje strona Cennik.
